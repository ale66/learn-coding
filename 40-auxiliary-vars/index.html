Auxiliary variables

Topics

  • counters

  • accumulators

  • trailers

Counters

A variable, normally of type integer, that is incremented as we parse an iterable

Example: compute list size/length

l = 0

for f in fruits:

  l = l +1

print(f'The length of list {fruits} is {l}')

Syntax: l += 1 is shorthand for l = l + 1

Anonymous variables

In fact, we are not operating on f

it can be omitted in favour of an anonymous variable _

l = 0

for _ in fruits:

  l += 1

print(f'The lenght of list {fruits} is {l}')

Accumulators

A variable to record quantities seen during the iteration

Example: the average of an arbitrary list of positive numbers

l = 0
accumulator = 0

for val in mylist:
  l += 1
  accumulator += val

if l > 0:
  average =  accumulator / l # this will be a float

print(f'There are {l} values and their average is {average}')

Trailing variables

A variable that remembers past values during an iteration

Example: find the biggest temperature increase in a list

# start with the minimum possible value
max_day_on_day_change = 0

# initialise the trailer variable
trailer = temperatures_this_month[0]

for temp in temperatures_this_month:

  # do your thing here...

  # we are finished with this value, assign it to the trailer

A more complete encoding

temperatures_this_month = [27, 21, 16, 21, 19, 18, 19, 12, 15, 12]

'''
Question: 
which day of the month has seen 
the steepest temperature change (either increasing or decreasing)?
'''
# start with the minimum possible value
max_day_on_day_change = 0

# initialise the trailer variable
trailer = temperatures_this_month[0]

for temp in temperatures_this_month:

  current_change = temp - trailer
  
  if abs(current_change) > max_day_on_day_change:
  
    max_day_on_day_change = abs(current_change) # a new max is found

  # we are finished with this value, assign it to the trailer
  trailer = temp

print(f'The maximum day-on-day increase has been {max_day_on_day_change} degrees')
